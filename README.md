# 探索中国开源生态 | Exploring China's Open Source Ecosystem

**大邱加图立大学 | OSS 应用与开发**  
**Daegu Catholic University | OSS Application and Development**

---

## 项目概述 | Project Overview

本项目深入探索中国开源生态，选取 **Vue.js** 作为研究对象，通过克隆仓库、分析社区、研究提交、健康检查等多个维度，全面了解全球顶级开源项目的运作机制。

This project explores China's open source ecosystem by selecting **Vue.js** as the research subject, comprehensively understanding the operational mechanisms of world-class open source projects through multiple dimensions including repository cloning, community analysis, commit research, and health assessments.
